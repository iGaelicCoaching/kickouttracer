KickoutArc - iGaelicCoach kickout tagging (standalone app)

QUICK START (this computer only)
  Unzip the folder somewhere permanent (e.g. Documents\KickoutArc) and double-click index.html.
  It opens in your browser. Games are saved in that browser on this computer.

BEST: PUT IT ONLINE FREE (GitHub Pages) AND INSTALL IT LIKE AN APP
  1. github.com (your igaeliccoaching account) -> New repository -> name it  kickoutarc  -> Public -> Create.
  2. "uploading an existing file" -> drag in ALL the files from this folder (index.html, manifest.webmanifest,
     sw.js, icon-192.png, icon-512.png) -> Commit changes.
  3. Settings -> Pages -> Branch: main, folder / (root) -> Save. Wait a minute.
  4. Open  https://igaeliccoaching.github.io/kickoutarc/  in Chrome or Edge.
  5. Click the install icon at the right of the address bar (or menu -> "Install KickoutArc").
     It gets its own window and a desktop / Start menu icon, and works with no internet.

WHERE YOUR GAMES ARE SAVED
  In the browser on the computer you tag on (not online). So:
  - Games page -> Backup now and then; keep the .json file somewhere safe (OneDrive, Google Drive).
  - New computer or browser: open KickoutArc there -> Games -> Restore -> pick the backup.
  - Clearing browsing data for the site deletes the games, so back up first.
  - Don't use a private/incognito window: nothing is kept.

MOVING GAMES FROM THE CLAUDE VERSION
  In the Claude version: Export CSV -> All games. In this app: Import CSV -> that file.

TO THE DATA HUB
  Export CSV -> put the file in the Data Hub's kickouts folder -> PUBLISH_TO_SHINYAPPS
  (or Kickouts -> Kickout maps -> Add a KickoutArc CSV for a quick look).

UPDATES
  Replace index.html (on GitHub: open it -> upload the new version). Your saved games are not touched.
